What the expression reads

Each fact below is read from every page of the document, then combined into the single value the expression sees.

The document is read one page at a time, so each fact gets one reading per page. The dropdown under a fact says how those readings are merged into the single value the expression uses:

yes if at least one page shows it
One page is enough.
yes only if every page that mentions it shows it
Pages that say nothing about it are ignored.
the list of page numbers where it appears
Not yes/no or a total, but the pages themselves, like [3, 7]. Pick this when the rule is about where something happens, for example, that an example must follow a formula within a few pages.
all pages added together
3 on one page and 2 on another make 5. For a yes/no fact this counts the pages where it's true.
the highest / lowest value on any page
One page's number: the biggest, or the smallest.
the first value found
Reading from page 1, the first page that has one.
every distinct item, from all pages
One combined list, without repeats.
each item with the page where it appears
Item–page pairs, like kinetic energy (p. 3), so the expression can match which item appears where. Works only if the wording above tells the reader to name items the same way on every page.

If you change a dropdown, the value can change shape, for example, a total can become a list of pages. Update the expression below to match.
